# b-cuda
[B-CUDA] BeBar Cuda

Collection of basic CUDA functions made available under the Apache 2.0 license, as well as some template files showing how to solve some basic parallel programming problems.

For compiling on Linux, run the "make" command. You may need to modify the Makefile to match your specific environment.

For compiling on Widows, run the "make.bat" file inside of command prompt.
